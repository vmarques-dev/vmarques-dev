### [PIB Vila Canaan](https://github.com/vmarques-dev/pib-vila-canaan) · `in production`

A full web platform for church management — with a public institutional website and a private administrative system. A real-world project, live in production, built independently.

**Tech Stack:** Next.js 15 · TypeScript · React · Tailwind CSS · Supabase · Resend

🔗 [View code](https://github.com/vmarques-dev/pib-vila-canaan) | 🌐 [Access platform](https://pib-vila-canaan.vercel.app)

**Technical highlights:**
- Architecture with App Router and React Server Components (Next.js 15)
- Dual authentication (members and administrators) with Row Level Security
- Full CRUD for events, Bible studies, and members
- PostgreSQL database via Supabase with profile-based security policies
- Continuous deployment on Vercel with separate environments (production/development)
- Conventional Commits standard applied throughout the project
