## 🚀 Projetos em Destaque

### [PIB Vila Canaan](https://github.com/vmarques-dev/pib-vila-canaan) · `em produção`

Plataforma web completa para gestão de uma igreja — com site público institucional e sistema administrativo privado. Projeto real, em produção, desenvolvido de forma independente.

**Tech Stack:** Next.js 15 · TypeScript · React · Tailwind CSS · Supabase · Resend

🔗 [Ver código](https://github.com/vmarques-dev/pib-vila-canaan) | 🌐 [Acessar plataforma](https://pib-vila-canaan.vercel.app)

**Destaques técnicos:**
- Arquitetura com App Router e React Server Components (Next.js 15)
- Autenticação dual (membros e administradores) com Row Level Security
- CRUD completo de eventos, estudos bíblicos e membros
- Banco de dados PostgreSQL via Supabase com políticas de segurança por perfil
- Deploy contínuo na Vercel com ambientes separados (produção/desenvolvimento)
- Padrão Conventional Commits aplicado ao longo do projeto
